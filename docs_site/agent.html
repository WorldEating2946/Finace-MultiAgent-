Research Agent

理解研究意图 → 生成结构化计划 → 逐步证据检索 → 合成带证据链的报告 → 质量评测。核心：LLM 只返回证据索引，来源/页码/原文由后端补全，无法编造。

六步流程

意图理解→ 计划生成→ 画像构建→ 逐步证据检索→ 报告合成→ 质量评测

抗幻觉设计（核心机制）

LLM 输出 JSON 时 只给证据索引，不输出证据内容：

{ "claims": [{ "text": "2025年小鹏交付量创新高", "evidence_refs": [2, 5] }] }

→ 后端用 ref_map 从真实 chunk 补全来源/页码/原文
→ 越界索引 静默丢弃；无证据 claim 保留但证据为空（宁缺毋滥）
→ 模型编造"第 3 页说…"很容易，但"引用第 2 条证据"后证据链必然真实
