检索链路演进（关键决策）

OCR 结构适配（PR30）

PDF outline 优先 TOC、数字误判过滤、繁体归一 → 小米 Recall@5 10% → 70%

LLM Query Rewrite（PR31）

理解意图消歧 → 小米 Recall 70% → 80%；base-first 防正确结果被挤出

Metadata Rerank（PR33）

α·CE + β·section + γ·keyword → 小米 MRR 0.26→0.42，Top1 10%→30%

PR44 向量层

FAISS/Milvus 精度逐项一致，延迟仅高 6~9%；离线评测钉死 FAISS 保证可复现
