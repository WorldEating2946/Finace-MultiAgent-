关键设计原则

原则说明
数据分类施策非结构化知识 → RAG；结构化数据 → Tool + 程序计算；实时舆情 → Search。LLM 不负责精确计算。
抗幻觉三件套LLM 只返回证据索引 → 越界索引丢弃 → 无证据 claim 保留但证据为空（宁缺毋滥）。
可评测每条论点可回源（章节/页码/原文 chunk），5 项质量指标量化，回归门禁守住基线。
可恢复Runtime 故障矩阵全覆盖：Worker 崩溃 / Redis 重启 / 旧进程复活 / 超时 / 重试超限均有明确恢复路径。
